# 探空资料组装台（Pair-wise Radiosonde Assembly）

本地应用：接收探空气球传感器按时间上报的气压、温度、湿度、位置和仪器状态包，
组装每次探空，自动区分**上升 / 漂浮 / 下降 / 终止**，从原始资料派生**标准压力层**
和带依据的质量标志；浏览器界面支持人工判定，人工层与自动层分离保存，剖面一经
签字即冻结，新算法重跑或迟到包都不能改写已发布的纵向剖面。

- Go 标准库 `net/http` 提供服务与 JSON API，前端为零依赖原生 HTML/SVG/JS
- 存储为本地 SQLite（纯 Go 驱动 `modernc.org/sqlite`，无需 CGO）
- 内置模拟器产生乱序、重复重试、载荷冲突、迟到包、气压短时反向、湿度结冰和 GPS 断点

## 运行

```bash
go mod download
go test ./... -count=1 && go run ./cmd/server --listen 127.0.0.1:5340
```

浏览器访问 <http://127.0.0.1:5340>。首次启动会自动创建一个演示探空（含全部
异常形态），并以 25 包/批的方式乱序灌入。

参数：`--listen` 监听地址，`--db` SQLite 文件路径（默认 `sonde.db`），
`--seed=false` 关闭空库自动演示。

## 页面

- **原始时线**：按序号的气压曲线，颜色为运动分支，虚线段为保留的候选轨迹，
  爆裂点有标注；点击任意点查看该点全部质量标志及文字依据。
- **高度/气压剖面**：高度对对数气压，分别绘制上升/漂浮/下降（GPS 断点处断开）。
- **分支转移**：每次分支切换的由→到阶段、触发依据（爆裂状态、气压平台、气压
  趋势反转、人工覆盖）和来源（自动/人工）。
- **重复包/候选轨迹**：同一序号出现不同载荷时列出全部候选，可选择一个可信版本，
  或勾选“保留两个候选轨迹”。
- **标准压力层**：按分支/运动组切换；给出高度、温度、湿度和状态（观测值/插值/
  冲突待定/缺失原因）。
- **质量标志依据**：未选点时汇总全飞行标志计数与通用依据，选点后列出逐点依据。

在时线选中一个点后：按 `d` 把一个区间标为下降资料，按 `i` 圈定结冰区间。
右上角填写人工号后可“发布当前剖面（签字）”。

## 数据口径

### 1. 时序去重与冲突

- 以 `(设备/探空, 序号, 载荷哈希)` 为主键。载荷哈希由序号、观测时间和全部观测
  值（气压、温、湿、纬经高、仪器状态）规范化计算，**不含接收时间**。
- 同一序号且载荷哈希相同 = 线缆**重试**：只记一条 `arrivals` 到达日志，不新增
  资料，不改变草稿版本。
- 同一序号但载荷哈希不同 = **冲突**：两个载荷都保留为候选（按首次到达排序，
  候选号 1..N 稳定分配），默认暂取最早到达版本并打 `duplicate_conflict` 标志。
- **迟到包**：当批最大序号之后才到达的更小号包。迟到包照常入库、产生新草稿版本，
  但在用户重新发布之前**不会改变任何已签字剖面**。
- 人工可对冲突做两种签字判定：选定唯一可信候选（其余仅作审计展示），或保留两个
  候选轨迹。保留两轨迹时，受影响标准层不产出签字值，只给
  `duplicate_conflict_unresolved` 缺失原因，并画出虚线候选轨迹。

### 2. 运动分支

- 自动分类基于滚动中位数（±2 点窗口）的气压倾向：压力下降=上升，上升=下降，
  |倾向| ≤ 0.2 hPa/样本 = 漂浮；短于 3 点的漂浮片段并入周围主导运动。
- `BURST` 仪器状态锚定爆裂后的下降段；出现 `TERMINATED` 之后的点全部记为终止。
- 气压短时反向：局部倾向与所在分支相反的单点打 `pressure_reversal` 标志，
  不删除资料；它能否参与插值由“同一运动组内能否被两个有效点夹住”自然决定。
- 上升途中被漂浮平台隔开的两段上升，界面上仍是独立分支、转移完整保留；派生标准
  层时二者共享一个**运动组**，平台样本自身不充当上升插值的端点。
- 人工阶段判定以带签字的时间区间覆盖自动结果（来源标为 `manual`），重跑自动
  算法不会覆盖。

### 3. 插值口径

- 标准层固定为 1000, 925, 850, 700, 500, 400, 300, 250, 200, 150, 100, 70,
  50, 30, 20, 10, 7, 5, 3, 2, 1 hPa。
- 观测气压与标准层相差 ≤ **0.05 hPa** 时直接使用该点观测值（`exact=true`）。
- 否则只在**两个有效、且属于同一运动分支/运动组**的点之间插值；高度与各要素对
  **对数气压**线性插值，时间按比例插值。
- **上升与下降同压力点绝不混合平均**：每个运动组独立产出层级，下降剖面与上升
  剖面分行展示。
- GPS 断点只使纬经（位置）缺失；气压、温度和由气压锚定的高度仍可插值。
- 湿度结冰：自动启发式（RH 持续 ≥98% 且传感器温度 ≤ −20℃，连续 ≥3 点）或人工
  区间，命中层的 RH 不给值，原因 `humidity_sensor_iced`。
- 未决的重复冲突使整层不给签字值（`duplicate_conflict_unresolved`，并置
  `ambiguous` 标志）。

### 4. 不能插值与缺失原因

无法派生的字段**保留缺失并记录原因**，绝不静默置零或跨分支借点：

| 原因 | 含义 |
| --- | --- |
| `below_branch_range` | 标准层低于该分支观测到的最低高度（地面侧） |
| `above_branch_range` | 标准层高于分支顶（如上升未到 10 hPa） |
| `no_same_branch_bracket` | 同分支/同运动组内没有两个有效点夹住该层 |
| `observation_missing` | 端点缺该要素观测 |
| `gps_breakpoint` | 位置处于 GPS 断点 |
| `humidity_sensor_iced` | 湿度传感器结冰，RH 不发布 |
| `duplicate_conflict_unresolved` | 保留双候选，未选定可信版本 |

主上升分支对每个标准层都产出一行（含越界缺失原因），其它分支只产出覆盖范围内
的层。

### 5. 批次、发布与并发

- **批次接收与剖面发布分离**：`POST /packets` 只做整批接收（一个 SQLite 事务，
  任一包失败整批回滚）；`POST /publish` 才把草稿冻结成签字剖面。
- 发布在**单个事务**内写剖面头和全部标准层；任何失败都不会出现“部分标准层已
  发布”。已发布的 `(探空, 版本)` 不可改写，重复发布返回 409。
- 每次实际入库的批次或人工判定都使草稿 `revision` 自增。人工判定请求带
  `expected_revision`，乐观并发失败返回 409，并在 `affected_time_range` 中给出
  与该时间段重叠的已签字判定（两人并发判定同一时间段时页面据此提示受影响区间）。
- 迟到包、新批次或算法重跑只产生新草稿；已签字剖面通过版本号 + 快照 +
  `published_levels` 表永久保持。

## HTTP API

| 方法/路径 | 说明 |
| --- | --- |
| `GET /api/soundings` | 列出探空及草稿/已发布版本 |
| `POST /api/soundings` | 新建探空 `{device_id,name}` |
| `GET /api/soundings/{id}/draft` | 当前草稿（时线、分支、层级、冲突、标志） |
| `POST /api/soundings/{id}/packets` | 整批接收 `{packets:[...]}`（原子） |
| `POST /api/soundings/{id}/simulate` | 灌入内置乱序/重放模拟流 `{batch_size}` |
| `POST /api/soundings/{id}/overrides` | 提交签字判定 `phase` / `icing` / `resolve` |
| `POST /api/soundings/{id}/publish` | 原子发布当前草稿 `{author,note}` |
| `GET /api/soundings/{id}/published` | 读取最新已冻结剖面 |

override 体示例：

```json
{ "expected_revision": 9, "kind": "phase", "phase": "descent",
  "start_time": "2026-09-21T00:19:00Z", "end_time": "2026-09-21T00:23:00Z",
  "author": "analyst-a", "note": "下降段" }
```

`kind="icing"` 用 `icing:true/false` 圈定/解除结冰；`kind="resolve"` 用
`seq` + `candidate_id`（候选号，`-1` 表示保留两个候选轨迹）。

## 代码结构

```
cmd/server            入口、参数、空库演示播种
internal/domain       包/点/分支/层级/质量标志核心类型
internal/derive       去重组装、运动分类、运动组、标准层插值与缺失原因
internal/store        SQLite schema、原子批次、乐观并发、原子且不可变的发布
internal/service      用例编排（接收≠发布；草稿=包+签字判定的纯函数）
internal/sim          合成飞行 + 乱序/重试/冲突/迟到/重放投递流
internal/server       HTTP API 与 embed 的浏览器界面（web/）
```

## 测试

`go test ./... -count=1` 覆盖：

- 派生：相位分类、爆裂/终止、观测值优先、同分支对数气压插值、升降不混合、
  重试/冲突区分、保留双轨迹不插值、人工下降覆盖、结冰 RH 缺失、GPS 位置缺失、
  越界层缺失原因。
- 存储：重试与冲突计数、迟到标志、失败批次整体回滚、发布全层原子、重复发布
  409、人工判定乐观冲突、并发发布只有一个赢家、重叠判定时间段报告。
- 模拟：四类异常齐全、冲突两载荷、迟到确实晚于后续包、重放确定性。
- HTTP 端到端：模拟灌入→草稿→发布→重复发布 409、迟到包不动已签字剖面、
  并发判定 409 且返回受影响时间段、空批次 400。
